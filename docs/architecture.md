## Схема из трёх узлов

```
Vue 3 + Vite             ASP.NET Core              PostgreSQL
localhost:5173  ───────► localhost:5000  ───────► обычно :5432
                  HTTP                    запросы к БД
```

**Это и есть архитектура web-ИС семестра.**  
Три узла, две связи, один источник правды о заявках. Прямой стрелки от браузера к базе данных нет.
