# Отчет по ЛР5: Форма и список в памяти

## Проверка работы

| **Проверка** | **Что делаете** | **Факт** |
| --- | --- | --- |
| Успех | тема ≥ 5, `siteId` > 0, описание ≥ 10 | строка со статусом `New` появилась |
| Отказ | тема `abc` | ошибки видна, строка не появилась |
| Память | F5 после успешного создания | добавленная строка ожидаемо исчезла |
