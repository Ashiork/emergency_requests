Все запросы идут на базовый адрес `http://localhost:5000`.  
Формат данных - JSON. Коды статусов только: `New`, `InProgress`, `Closed`, `Cancelled`.

## 1\. Сводная таблица

| Метод и путь | Что прислать (тело) | Успех | Возможные ошибки |
| --- | --- | --- | --- |
| `GET /api/tickets` | \- | 200, массив заявок (или `[]`) | \- |
| `GET /api/tickets/{id}` | \- | 200, объект заявки | 404 |
| `POST /api/tickets` | `title`, `siteId`, `description` | 201, `id`, `number`, `status: New` | 400 |
| `PATCH /api/tickets/{id}/assignee` | `assignee` | 200, объект заявки | 404 |
| `PATCH /api/tickets/{id}/status` | `status` | 200, объект заявки | 404, 409 |

**Важно:**

*   `id` и `number` в адресе и теле запроса - это разные вещи. В URL используется машинный `id` (`/api/tickets/17`).
*   Действие "назначить" и действие "сменить статус" разделены на два разных `PATCH`.
*   Удаление (`DELETE`) не предусмотрено: отмена - это смена статуса на `Cancelled`.

## 2\. Примеры запросов и ответов

### 2.1. Создание заявки - `POST /api/tickets`

**Тело запроса (клиент присылает):**

```
json
{
  "title": "Прорыв на теплосети",
  "siteId": 3,
  "description": "Обнаружена утечка теплоносителя во дворе дома"
}
```

**Ответ сервера (201 Created)**

```
json
{
  "id": 17,
  "number": "AVR-2026-0017",
  "title": "Прорыв на теплосети",
  "description": "Обнаружена утечка теплоносителя во дворе дома",
  "status": "New",
  "siteId": 3,
  "createdBy": 1,
  "assignee": null,
  "createdAt": "2026-10-11T10:00:00Z",
  "updatedAt": "2026-10-11T10:00:00Z"
}
```

### 2.2. Назначение исполнителя - `PATCH /api/tickets/{id}/assignee`

**Тело запроса:**

```
json
{
  "assignee": 5
}
```

**Ответ сервера (200 OK):**

```
json
{
  "id": 17,
  "number": "AVR-2026-0017",
  "status": "New",
  "assignee": 5,
  "updatedAt": "2026-10-11T10:05:00Z"
}
```

### 2.3. Смена статуса - `PATCH /api/tickets/{id}/status`

**Тело запроса (взять в работу):**

```
json
{
  "status": "InProgress"
}
```

**Ответ сервера (200 OK):**

```
json
{
  "id": 17,
  "number": "AVR-2026-0017",
  "status": "InProgress",
  "assignee": 5,
  "updatedAt": "2026-10-11T10:15:00Z"
}
```

**Ошибка 409 Conflict:**

Возвращается, если правила нарушены. Например, бригадир пытается закрыть заявку, которая еще не в работе, или диспетчер пытается сменить статус (это не его роль).

### 2.4. Получение списка - `GET /api/tickets`

**Ответ сервера (200 OK):**

Если заявок нет, сервер возвращает 200 OK и пустой массив.

```
json
[
  {
    "id": 17,
    "number": "AVR-2026-0017",
    "title": "Прорыв на теплосети",
    "status": "InProgress",
    "assignee": 5
  },
  {
    "id": 18,
    "number": "AVR-2026-0018",
    "title": "Нет ГВС",
    "status": "New",
    "assignee": null
  }
]
```
